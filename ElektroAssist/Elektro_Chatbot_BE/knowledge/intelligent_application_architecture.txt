Arsitektur Aplikasi Cerdas – Desain Sistem End-to-End untuk Elektro

1. Visi Aplikasi

   - Nama: ElectroAssist
   - Pengguna: mahasiswa teknik elektro & teknisi listrik
   - Tujuan: satu aplikasi untuk pembelajaran, troubleshooting, desain, dan monitoring

2. Komponen Inti Sistem

   a. Knowledge Engine:
      • 40+ dokumen teknis (power, embedded, networking, renewable, AI)
      • Retrieval sederhana berbasis keyword (bisa di-upgrade ke embedding)
      • Update manual: tambah file .txt → restart backend

   b. AI Reasoning Layer:
      • Google Gemini 1.5 Flash (cepat) / Pro (akurat)
      • Function calling: panggil fungsi Go untuk kalkulasi teknis
        - Hitung drop tegangan
        - Estimasi kapasitas baterai
        - Konversi satuan
      • Safety guardrails: "Jangan tebak angka teknis"

   c. Hardware Integration Module:
      • REST API untuk terima data dari perangkat (ESP32, Raspberry Pi)
      • WebSocket untuk dashboard real-time
      • Simulasi mode: untuk pengguna tanpa hardware

   d. User Interface:
      • Android (Kotlin): mobile-first, untuk teknisi di lapangan
      • Web (opsional): untuk mahasiswa di lab
      • Fitur: chat, dashboard, library dokumen, notifikasi

3. Alur Pengguna Nyata

   Skenario 1: Mahasiswa Tugas Rangkaian
   - Input: "Bantu saya desain catu daya 5V 1A dari 12V"
   - Sistem:
     • Ambil `power_supply_design.txt`
     • Saran: "Gunakan LM7805 dengan heatsink, input ≥7V"
     • Fungsi: hitung disipasi panas = (12-5)*1 = 7W → butuh heatsink besar

   Skenario 2: Teknisi di Lapangan
   - Input: "MCB 16A trip terus di sirkit AC"
   - Sistem:
     • Ambil `common_troubleshooting_guide.txt` + `protective_devices_coordination.txt`
     • Saran: "Cek short circuit, beban >2800W, atau ground fault. Ukur arus start AC (bisa 5x normal)."

   Skenario 3: Monitoring PLTS
   - Perangkat: ESP32 + sensor arus/tegangan kirim data ke backend
   - Aplikasi: tampilkan grafik produksi & konsumsi
   - Chatbot: "Hari ini produksi 12 kWh, cukup untuk 80% kebutuhan Anda."

4. Teknologi Stack

   - Frontend: Kotlin (Android) → clean architecture, Retrofit, Coroutines
   - Backend: Go → Gin, WebSocket, Google AI SDK
   - Knowledge Base: file .txt di direktori lokal
   - Hosting: Railway (backend), Vercel (web), Google Play (Android)
   - AI: Google Gemini 1.5 (Flash/Pro) + RAG lokal
   - Opsional: InfluxDB untuk data time-series

5. Keunggulan Dibanding Aplikasi Umum

   - Domain-specific: tidak umum seperti ChatGPT
   - Fakta berbasis dokumen: hindari halusinasi teknis
   - Dua sisi: arus rendah & arus tinggi
   - Praktis: fokus pada pertanyaan nyata teknisi/mahasiswa
   - Portabel: bisa jalan tanpa internet (jika knowledge base lokal)

6. Evaluasi Sistem (Untuk Skripsi)

   - Metrik:
     • Akurasi teknis (divalidasi ahli)
     • Waktu respons
     • Cakupan topik (jumlah skenario terlayani)
   - Metode:
     • Kumpulkan 50 pertanyaan nyata dari pengguna target
     • Bandingkan jawaban ElectroAssist vs manual/ahli
     • Survei kegunaan (usability)

7. Roadmap Pengembangan

   Tahap 1 (Skripsi): chatbot + knowledge base + mock hardware
   Tahap 2: integrasi hardware nyata (ESP32 + sensor)
   Tahap 3: tambah fitur monitoring & notifikasi
   Tahap 4: deploy ke Google Play & uji lapangan

8. Kesimpulan Desain

   Sistem ini membuktikan bahwa:
   - LLM bisa dikendalikan untuk domain teknis
   - Knowledge base lokal cukup efektif tanpa fine-tuning
   - Integrasi Go + Kotlin + Gemini + dokumen teknis = solusi holistik
   - Skripsi bukan hanya teori, tapi produk nyata yang berguna
