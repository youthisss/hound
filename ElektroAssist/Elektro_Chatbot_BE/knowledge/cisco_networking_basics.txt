Dasar Jaringan Cisco – Perangkat & Konfigurasi

1. Jenis Perangkat Cisco:
   - Switch (Catalyst 2960/3560): untuk LAN, layer 2/3
   - Router (ISR 1000/4000): untuk routing antar jaringan
   - Wireless Controller (WLC): kelola access point
   - Firewall (ASA/Firepower): proteksi keamanan

2. Mode Akses CLI:
   - User EXEC: `Router>` → perintah dasar (show, ping)
   - Privileged EXEC: `Router#` → akses penuh
   - Global Config: `Router(config)#` → ubah konfigurasi

3. Perintah Dasar:
   - Masuk config: `enable` → `configure terminal`
   - Atur hostname: `hostname SW-LAB`
   - Atur IP interface:  
     ```
     interface vlan 1
     ip address 192.168.1.10 255.255.255.0
     no shutdown
     ```
   - Simpan konfigurasi: `copy running-config startup-config`

4. VLAN (Virtual LAN):
   - Pisahkan lalu lintas (misal: IoT, kantor, kontrol)
   - Contoh:  
     ```
     vlan 10
     name IOT_DEVICES
     interface gigabit0/1
     switchport mode access
     switchport access vlan 10
     ```

5. Routing Statis:
   -ip route 10.0.0.0 255.0.0.0 192.168.1.1

6. Keamanan Dasar:
- Nonaktifkan service tidak perlu: `no ip http server`
- Atur password: `enable secret mypass`
- Gunakan SSH, bukan Telnet:  
  ```
  ip domain-name elektro.local
  crypto key generate rsa
  line vty 0 4
  transport input ssh
  ```

7. Relevansi untuk Elektro:
- Integrasi SCADA: VLAN terpisah untuk RTU
- Smart building: switch Cisco untuk PoE ke sensor/camera
- QoS: prioritaskan lalu lintas kontrol (misal: Modbus TCP)
