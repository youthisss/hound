Jaringan Industri – Protokol & Aplikasi di Dunia Elektro

1. Modbus:
   - Protokol serial (RTU) atau TCP/IP
   - Master-slave: PLC sebagai master, sensor/meter sebagai slave
   - Register: coil (0x), input discrete (1x), input register (3x), holding register (4x)
   - Contoh: membaca daya dari meter listrik via Modbus TCP

2. Profibus:
   - Kecepatan tinggi (9.6 kbps – 12 Mbps)
   - Dipakai di pabrik berat (otomotif, kimia)
   - Butuh terminator di ujung kabel

3. Ethernet/IP:
   - Berbasis Ethernet standar, tapi pakai CIP (Common Industrial Protocol)
   - Digunakan oleh Allen-Bradley/Rockwell
   - Mendukung real-time I/O dan pesan eksplisit

4. DNP3 (Distributed Network Protocol):
   - Khusus untuk sistem tenaga (SCADA)
   - Mendukung time-stamping, event buffering, dan keamanan dasar
   - Dipakai antara RTU dan master station di PLN

5. IEC 61850:
   - Standar global untuk substation automation
   - Menggunakan GOOSE (Generic Object Oriented Substation Event) untuk komunikasi real-time <4ms
   - Semua perangkat di substation punya model data terstandar

6. Topologi & Kabel:
   - RS-485: untuk Modbus RTU, jarak sampai 1200m, multidrop
   - Fiber optic: untuk jarak jauh & noise immunity (gardu listrik)
   - Switch industri: rugged, mendukung VLAN, redundancy (RSTP)

7. Keamanan:
   - Jangan gabung jaringan kontrol dengan jaringan kantor
   - Gunakan firewall industri (misal: Siemens SCALANCE)
