Machine Learning untuk Insinyur Teknik

1. Jenis ML Relevan untuk Elektro:
   - Supervised: prediksi beban listrik, klasifikasi gangguan
   - Unsupervised: deteksi anomali (arus bocor, noise)
   - Reinforcement: optimasi sistem tenaga

2. Algoritma Umum:
   - Linear/Logistic Regression: untuk prediksi sederhana
   - Decision Tree / Random Forest: interpretabel, akurat
   - SVM: untuk klasifikasi sinyal (misal: ECG, fault detection)
   - Neural Network kecil: untuk embedded (TensorFlow Lite)

3. Deployment di Edge:
   - TensorFlow Lite Micro: untuk mikrokontroler (ESP32, Arduino Nano 33 BLE)
   - ONNX Runtime: untuk model ringan di perangkat x86/ARM
   - Quantization: turunkan presisi (32-bit → 8-bit) untuk hemat memori

4. Studi Kasus Elektro:
   - Prediksi konsumsi listrik berdasarkan cuaca & jam
   - Klasifikasi suara trafo: normal vs gangguan
   - Deteksi kebocoran arus via pola konsumsi

5. Tools:
   - Python: scikit-learn, TensorFlow, PyTorch
   - Embedded: Edge Impulse, Arduino_TensorFlowLite
   - Cloud: Google Vertex AI, AWS SageMaker (untuk training)

6. Batasan:
   - Jangan pakai ML jika aturan logika cukup (misal: "jika I > 16A → trip")
   - Validasi dengan data nyata, bukan hanya akurasi training
