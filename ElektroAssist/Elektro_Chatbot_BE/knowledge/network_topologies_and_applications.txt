Topologi Jaringan – Jenis, Karakteristik, dan Aplikasi di Dunia Elektro

1. Topologi Bus:
   - Ciri: semua node terhubung ke satu kabel backbone
   - Media: kabel coaxial (dulu), RS-485 (masih dipakai)
   - Kelebihan: hemat kabel, sederhana
   - Kekurangan: satu gangguan putuskan seluruh jaringan
   - Aplikasi: Modbus RTU di panel kontrol, sistem alarm lama

2. Topologi Star:
   - Ciri: semua node terhubung ke central hub/switch
   - Media: UTP (Cat5e/Cat6), fiber
   - Kelebihan: gangguan lokal tidak ganggu jaringan, mudah ekspansi
   - Kekurangan: tergantung pada central device
   - Aplikasi: LAN kantor, smart building, IoT gateway

3. Topologi Ring:
   - Ciri: node tersambung melingkar, data berputar
   - Media: fiber optic, twisted pair
   - Kelebihan: bandwidth terbagi rata, redudansi (jika dual-ring)
   - Kekurangan: penambahan node ganggu jaringan
   - Aplikasi: jaringan industri (PROFINET MRP), substation automation (IEC 61850)

4. Topologi Mesh:
   - Ciri: setiap node terhubung ke beberapa node lain
   - Jenis:
     • Full mesh: semua saling terhubung (mahal)
     • Partial mesh: hanya node kritis yang redudan
   - Kelebihan: fault-tolerant, rute alternatif
   - Kekurangan: kompleks, boros kabel/daya
   - Aplikasi: Zigbee/Thread untuk smart home, jaringan sensor wireless

5. Topologi Tree/Hybrid:
   - Ciri: kombinasi star + bus
   - Aplikasi: jaringan distribusi listrik dengan RTU bertingkat, smart grid

6. Pemilihan Topologi – Panduan Praktis:
   - Jumlah node < 10? → Star
   - Jarak jauh & kabel terbatas? → Bus (RS-485)
   - Butuh redudansi tinggi? → Ring atau Mesh
   - Daya terbatas (baterai)? → Star atau Mesh (BLE/Zigbee)
   - Noise tinggi (pabrik)? → Fiber ring atau RS-485 bus

7. Pertimbangan Fisik oleh Teknisi Elektro:
   - Panjang maks kabel UTP: 100 meter
   - Panjang maks RS-485: 1200 meter (pada 100 kbps)
   - Gunakan kabel shielded di dekat inverter/motor
   - Grounding switch & perangkat wajib untuk hindari ground loop
