Desain Sistem Tertanam (Embedded Systems)

1. Arsitektur:
   - MCU (Microcontroller): CPU + RAM + Flash + peripheral (ATmega, ESP32, STM32)
   - MPU (Microprocessor): butuh RAM/ROM eksternal (Raspberry Pi, BeagleBone)

2. Real-Time Operating System (RTOS):
   - FreeRTOS: ringan, open-source, untuk ESP32/STM32
   - Zephyr: untuk perangkat sangat terbatas
   - Fitur: task scheduling, queue, semaphore

3. Komponen Sistem:
   - Bootloader: awal eksekusi, update firmware OTA
   - Watchdog timer: reset otomatis jika sistem hang
   - Power management: sleep mode, clock gating

4. Komunikasi Embedded:
   - Serial: UART, SPI, I2C
   - Wireless: BLE, Wi-Fi, LoRa, NB-IoT
   - Industrial: CAN bus, Modbus, RS-485

5. Desain Aman:
   - Secure boot: pastikan firmware asli
   - Enkripsi data sensor
   - Update firmware terenkripsi

6. Debugging:
   - JTAG/SWD: untuk debug hardware
   - Log serial: untuk troubleshooting
   - Oscilloscope: ukur timing sinyal

7. Contoh Aplikasi:
   - Smart meter dengan LoRa
   - Kontrol motor dengan feedback encoder
   - Sensor lingkungan dengan OTA update
