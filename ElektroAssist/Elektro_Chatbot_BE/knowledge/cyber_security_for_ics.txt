Keamanan Siber untuk Sistem Elektro & Industri

1. Ancaman Utama:
   - Malware di HMI/SCADA
   - Serangan DoS ke RTU
   - Manipulasi data sensor
   - Eksploitasi default password

2. Prinsip Keamanan:
   - Defense in depth: lapisan proteksi
   - Least privilege: akses minimal
   - Zero Trust: verifikasi semua akses

3. Segmentasi Jaringan:
   - Pisahkan OT (Operational Technology) dan IT
   - Gunakan VLAN atau firewall industri
   - DMZ untuk akses eksternal

4. Hardening Perangkat:
   - Nonaktifkan layanan tidak perlu (Telnet, FTP)
   - Ganti password default
   - Update firmware rutin

5. Enkripsi & Autentikasi:
   - TLS/SSL untuk komunikasi (MQTT over TLS)
   - Sertifikat digital, bukan hanya password
   - Secure boot & signed firmware

6. Standar:
   - IEC 62443: keamanan sistem otomasi industri
   - NIST SP 800-82: panduan keamanan ICS

7. Untuk Proyek Mahasiswa:
   - Jangan biarkan perangkat IoT terbuka ke internet
   - Gunakan autentikasi di REST API
   - Simpan API key di secure element (jika tersedia)
