Dasar Jaringan untuk Lulusan Teknik Elektro

1. Model OSI vs TCP/IP:
   - Lapisan Fisik (1): kabel, tegangan, konektor → **domain elektro!**
   - Lapisan Data Link (2): MAC address, switch, error detection
   - Lapisan Jaringan (3): IP address, routing, router
   - Lapisan Transport (4): TCP (andal) vs UDP (cepat, tanpa jaminan)
   - Lapisan Aplikasi (5-7): HTTP, MQTT, Modbus TCP

2. Alamat Jaringan:
   - MAC address: 48-bit, unik per perangkat (contoh: `A4:56:12:FF:0B:33`)
   - IP address: logika pengalamatan (IPv4: 192.168.1.10)
   - Subnet mask: tentukan jaringan vs host (contoh: `255.255.255.0` = /24)

3. Perangkat Jaringan & Peran Elektro:
   - Switch: operasi layer 2, forward berdasarkan MAC → instalasi & kabel
   - Router: layer 3, routing antar jaringan → konfigurasi IP
   - Gateway: antar protokol (misal: Modbus RTU → Modbus TCP)
   - Repeater: perkuat sinyal fisik (layer 1) → penting untuk RS-485 panjang

4. Media Transmisi:
   - UTP (Unshielded Twisted Pair): murah, untuk kantor (Cat5e = 1 Gbps)
   - STP (Shielded): untuk area noise tinggi (pabrik)
   - Fiber optic: jarak jauh, immune noise, untuk gardu listrik
   - Wireless: Wi-Fi, BLE, LoRa — pilih sesuai jarak & daya

5. Protokol Penting untuk Elektro:
   - Modbus TCP: port 502, untuk komunikasi meter/PLC
   - MQTT: port 1883, ringan untuk IoT
   - HTTP/HTTPS: untuk REST API sensor
   - NTP: sinkronisasi waktu (penting untuk SCADA)

6. Troubleshooting Dasar:
   - `ping`: cek konektivitas layer 3
   - `arp -a`: lihat MAC vs IP di jaringan lokal
   - `ipconfig` (Windows) / `ip a` (Linux): lihat konfigurasi IP
   - LED switch: mati = kabel putus, kuning = duplex mismatch

7. Keamanan Minimal:
   - Ganti password default perangkat
   - Pisahkan jaringan kontrol & jaringan kantor (VLAN)
   - Nonaktifkan layanan tidak perlu (Telnet, HTTP)
   - Gunakan VLAN untuk isolasi perangkat IoT
