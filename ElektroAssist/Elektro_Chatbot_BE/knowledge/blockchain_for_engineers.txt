Blockchain untuk Insinyur Teknik

1. Prinsip Dasar:
   - Distributed ledger: data disalin di banyak node
   - Immutability: data tidak bisa diubah setelah dikonfirmasi
   - Consensus: mekanisme validasi (PoW, PoS, PBFT)

2. Aplikasi di Dunia Elektro:
   - Peer-to-peer energy trading: jual-beli listrik PLTS antar rumah
   - Supply chain tracking: asal komponen elektronik
   - Audit log: rekam perubahan konfigurasi SCADA
   - Sertifikasi data sensor: pastikan tidak dimanipulasi

3. Platform:
   - Ethereum: smart contract fleksibel, tapi mahal
   - Hyperledger Fabric: permissioned, untuk enterprise
   - IOTA: untuk IoT ringan (Tangle, bukan blockchain murni)

4. Integrasi dengan Sistem Elektro:
   - Gateway IoT kirim data ke blockchain via API
   - Smart contract otomatis eksekusi pembayaran (jika produksi > X kWh)

5. Batasan:
   - Tidak cocok untuk data besar (video, log real-time)
   - Latensi tinggi (konfirmasi butuh waktu)
   - Biaya transaksi (untuk public chain)

6. Untuk Skripsi/Proyek:
   - Fokus pada use case spesifik, bukan teknologi itu sendiri
   - Simulasi dengan private blockchain (Ganache, Hyperledger)
