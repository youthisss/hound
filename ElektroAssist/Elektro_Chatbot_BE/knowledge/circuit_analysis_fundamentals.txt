Analisis Rangkaian – Hukum & Metode Dasar

1. Hukum Ohm: V = I × R

2. Hukum Kirchhoff:
   - Arus (KCL): Jumlah arus masuk simpul = jumlah arus keluar.
   - Tegangan (KVL): Jumlah tegangan di loop tertutup = 0.

3. Rangkaian Seri:
   - Arus sama di semua komponen.
   - R_total = R1 + R2 + ...
   - V_total = V1 + V2 + ...

4. Rangkaian Paralel:
   - Tegangan sama di semua cabang.
   - 1/R_total = 1/R1 + 1/R2 + ...
   - I_total = I1 + I2 + ...

5. Pembagi Tegangan:
   V_out = V_in × (R2 / (R1 + R2))

6. Pembagi Arus:
   I1 = I_total × (R2 / (R1 + R2))

7. Teorema Thevenin:
   Rangkaian linear → V_th (tegangan open-circuit) + R_th (resistansi input).

8. Teorema Norton:
   Rangkaian linear → I_n (arus short-circuit) + R_n (paralel).
