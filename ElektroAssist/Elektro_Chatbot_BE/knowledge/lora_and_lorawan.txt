LoRa & LoRaWAN – Komunikasi Jarak Jauh, Daya Rendah

1. LoRa (Physical Layer):
   - Modulasi: Chirp Spread Spectrum (CSS)
   - Frekuensi: 920–923 MHz (Indonesia, sesuai regulasi Kominfo)
   - Jarak: 2–15 km (tergantung lingkungan)
   - Kecepatan data: 0.3–50 kbps
   - Konsumsi daya: ~10–100 mA (transmit), ~1.5 µA (sleep)

2. LoRaWAN (Network Layer):
   - Arsitektur: End Device → Gateway → Network Server → Application
   - Kelas perangkat:
     • Class A: paling hemat daya (kirim → buka jendela terima)
     • Class C: selalu siap terima (untuk aktuator)
   - OTAA vs ABP:
     • OTAA: join otomatis, aman, butuh aktivasi
     • ABP: konfigurasi manual, lebih cepat

3. Perangkat Umum:
   - Modul: SX1276 (LoRa), RFM95
   - Board: ESP32 + LoRa (Heltec, TTGO)
   - Gateway: Multitech, Kerlink, atau rakitan Raspberry Pi + concentrator

4. Contoh Aplikasi Elektro:
   - Smart meter: kirim pemakaian listrik tiap jam
   - Sensor lingkungan: suhu, kelembaban di gardu listrik
   - Deteksi kebocoran arus di instalasi rural

5. Konfigurasi ESP32 + LoRa (Arduino):
   ```cpp
   #include <LoRa.h>
   void setup() {
     LoRa.setPins(SS, RST, DIO0);
     if (!LoRa.begin(923E6)) while (1); // 923 MHz
   }
   void loop() {
     LoRa.beginPacket();
     LoRa.print("arus=5.2A");
     LoRa.endPacket();
     delay(10000); // kirim tiap 10 detik
   }

6. Regulasi Indonesia:
   - Frekuensi LoRa: 920.5–923.5 MHz (channelized)
   - Daya maks: 500 mW (27 dBm)
   - Duty cycle: terbatas per channel

7. Kelebihan vs Zigbee/Wi-Fi:
   - Jangkauan jauh
   - Tembus bangunan
   - Baterai tahan bertahun-tahun
