Sistem Operasi untuk Insinyur Elektro

1. Jenis OS:
   - Real-Time OS (RTOS): FreeRTOS, Zephyr → deterministik, untuk kontrol
   - Embedded Linux: Yocto, Buildroot → untuk gateway IoT (Raspberry Pi)
   - Desktop/Server: Linux (Ubuntu), Windows → untuk development & server

2. Kernel:
   - Monolithic: semua layanan di kernel space (Linux)
   - Microkernel: layanan di user space (QNX, sebagian Zephyr)

3. Manajemen Proses:
   - Process vs Thread: thread berbagi memori, lebih ringan
   - Scheduling: round-robin, priority-based

4. Manajemen Memori:
   - Virtual memory: hanya di sistem dengan MMU (Linux)
   - Static allocation: umum di RTOS (hindari malloc/free)

5. File System:
   - FAT32: untuk SD card di embedded
   - ext4: untuk Linux
   - LittleFS: untuk flash internal mikro

6. Inter-Process Communication (IPC):
   - Pipes, sockets, shared memory, message queues

7. Relevansi Elektro:
   - Pilih RTOS untuk kontrol motor real-time
   - Pilih Embedded Linux untuk gateway dengan web server
   - Hindari OS general-purpose di perangkat kritis
